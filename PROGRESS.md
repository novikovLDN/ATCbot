## Как продолжать

1. Границы блоков считать по AST, а не по номерам строк: разрез по строкам
   один раз прошёл посреди функции.
2. После каждого выноса гонять `ruff` — тесты не видят потерянных импортов,
   потому что в них нет доступа к БД. Так уже трижды находились `asyncpg`,
   `hashlib`, `_normalize_subscription_row`.
3. Перекрёстные зависимости между новыми модулями делать локальными
   импортами и писать причину в комментарии — иначе кольцо импортов.
4. Каждый новый роутер обязательно подключать в `__init__.py` пакета:
   забытый `include_router` не даёт никакой ошибки, кнопки просто молчат.
