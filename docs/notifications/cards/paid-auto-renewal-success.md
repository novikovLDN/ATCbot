# Платная: «Подписка автоматически продлена» (с баланса)

[← к оглавлению](../README.md) · вердикт: ❌

| | |
|---|---|
| Ключ | i18n `purchase.auto_renewal_success` (без реестра) |
| Сегмент | платная, `auto_renew = TRUE`, баланс ≥ цены |
| Когда | в окне ≤6 ч до `expires_at`, после успешного списания |
| Воркер | auto_renewal, 10 мин (env 5–15) |
| Дедупликация | `payments.notification_sent` |

## Назначение
Подтвердить списание с баланса и новую дату окончания.

## Сегмент
`status='active' AND auto_renew AND expires_at ∈ (now; now + 6 ч] AND uuid IS NOT NULL AND is_reachable AND (last_auto_renewal_at IS NULL OR < expires_at − 12 ч)` — `auto_renewal.py:74-87`.

## Триггер и окно
- Окно `RENEWAL_WINDOW_HOURS = 6` (`auto_renewal.py:42-45`).
- В одной транзакции: `FOR UPDATE SKIP LOCKED` (`:87, 115-122`), `last_auto_renewal_at = now` (`:157-165`), цена по последнему платежу (`:187-226`), `decrease_balance` + `grant_access(source='auto_renew')` (`:235-254`), запись в `payments` (`:325-328`).
- Уведомление — **после коммита** (фаза B, `:377-458`).

## Воркер и период
`auto_renewal_task`: первый прогон сразу при старте (`:503-512`), затем раз в 600 с (`:35-39, 610`), таймаут 120 с (`:30, 561`). Включается фичефлагами (`main.py:481-485`).

## Источник данных
БД (баланс, последний платёж, тарифы из `config.TARIFFS`).

## Фильтр получателей
`is_reachable` в **запросе автопродления** — пользователь, однажды помеченный недоступным, больше не продлевается вообще ([N-02](../bugs-and-risks.md#n-02)).

## Текст
- RU (`app/i18n/ru.py:874`):
  ```
  <tg-emoji emoji-id="5456140674028019486">🔄</tg-emoji> <b>Подписка автоматически продлена</b>

  📦 Тариф: {tariff_name}
  <tg-emoji emoji-id="5454415424319931791">⏳</tg-emoji> Срок: {days} дней
  📅 Действует до: {expires_date}
  💳 Списано с баланса: {amount:.2f} ₽

  Ваш VPN продолжает работать без перерыва.

  🛡 Спасибо за доверие Atlas Secure!
  ```
- EN (`app/i18n/en.py:1014`) ✅.
- **`{amount}` всегда 0**: payload содержит `amount_rubles` (`auto_renewal.py:354`), а читается `item.get("amount", 0)` (`:418-421`) ([N-06](../bugs-and-risks.md#n-06), скрипт §5).
- `{tariff_name}` собирается в коде по-русски (`:407-416`); `is_combo` в payload нет — «Комбо» не показывается.
- `{expires_date}` в UTC (`:343`, [N-19](../bugs-and-risks.md#n-19)).
- Кнопка захардкожена: «👤 Мой профиль» → `menu_profile` (`:429-431`), по-русски и для EN.
- Не используется: `main.auto_renewal_success` (`ru.py:475`).

## Переопределение из дашборда
Нет.

## Дедупликация
- `payments.notification_sent` (`database/core.py:156-190, 650-652`) ставится после отправки (`auto_renewal.py:444`).
- Проверка `check_notification_idempotency` (`:334-341`) выполняется для только что вставленного платежа и всегда даёт FALSE — бессмысленна, но безвредна.
- Повторного продления не будет благодаря `last_auto_renewal_at` + блокировке строк ✅.

## Риски задвоения
✅ Нет: платёж создаётся один раз на продление, повторных проходов по `payments` нет.

## Риски потери
- ⚠️ `safe_send_message` вернул `None` (включая временную ошибку) → `continue`, повтора нет (`:432-434`).
- ⚠️ Падение процесса между коммитом и отправкой — потеря.
- ❌ Нехватка баланса — никакого уведомления, и повтора после пополнения нет ([N-12](../bugs-and-risks.md#n-12)).

## Вердикт
❌ **Баг**: неверная сумма в каждом сообщении, плюс RU-хардкод.
