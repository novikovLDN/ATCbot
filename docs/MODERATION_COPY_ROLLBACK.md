# Moderation copy rollback — журнал замен терминологии

Назначение: под модерацию сторов из пользовательских текстов бота убраны
упоминания **VPN**, **«обход»** и **«белые списки»**. Этот файл — карта замен,
чтобы при необходимости откатить всё обратно.

Файлы затронуты: `app/i18n/ru.py`, `app/i18n/en.py` (только строковые **значения**;
имена ключей, `callback_data`, код и комментарии НЕ менялись).

## Как откатить

- **Полный откат обоих проходов** (git):
  ```
  git revert <commit-moderation> <commit-refine>
  ```
  где `<commit-moderation>` — коммит «подготовка к модерации — VPN→VPS, обход→Pro…»,
  `<commit-refine>` — коммит «уточнение понятий (Pro-режим)». Найти:
  `git log --oneline --grep "модерац\|Pro-режим"`.
- **Частичный откат** (вернуть отдельные строки): по таблице ниже замените
  новый термин на исходный в нужном ключе `app/i18n/*.py`.

## Проходы

1. **Проход 1 — модерация (ru + en).** Термины заменены во всех экранах.
2. **Проход 2 — уточнение понятий (ТОЛЬКО ru).** Голое/непонятное «Pro»
   заменено на понятные формы. **Уведомления (`traffic.notify_*`) НЕ трогались** —
   в них намеренно осталось короткое «Pro»/«Pro-трафик». Английский во 2-м
   проходе не менялся.

## НЕ трогалось (намеренно)

- Имена ключей-идентификаторов: `*_bypass_*`, `info_bypass_*`, `my_sub_bypass_*`,
  `key_whitelist`, `buy.biz_pro_*` и т.п. — это идентификаторы, не текст.
- Легитимные «Pro», не относящиеся к фиче обхода: бизнес-тариф **Pro**
  (`buy.biz_pro_btn`, `buy.tariff_biz_pro_desc`), **Claude Pro/Max**
  (`shop.*`), метки **Happ Pro / Incy Pro** (`setup.happ_bypass_label` /
  `setup.incy_bypass_label`).
- Слово **«необходимо»** (содержит подстроку «обход», но не относится к фиче).
- Уведомления `traffic.notify_*` — не уточнялись во 2-м проходе.
- Английские тексты во 2-м проходе (уточнение) — не менялись.

## Глоссарий понятий (для будущих правок)

- **Pro-режим** — фича доступа к нужным/заблокированным сайтам (бывш. «обход
  белых списков»).
- **Pro-серверы** — серверы этого режима (бывш. «сервера обхода»).
- **Pro-трафик / ГБ Pro-трафика** — оплачиваемый трафик режима (бывш. «трафик
  обхода»).
- **Pro-ключ** — ключ подключения к Pro-серверам (бывш. «ключ обхода»).
- **VPS** — основные серверы (бывш. «VPN»).
