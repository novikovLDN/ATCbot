# Чек-лист для владельца: проверь в боте — используешь ли?

Отметь `[x]` там, где ответ «да, нужно». Там, где сомневаешься, пришли скриншот, как экран выглядит у тебя. Всё, что останется без отметки, уйдёт в пакеты удаления из [candidates.md](candidates.md). Удаление начнём только после твоего «ок».

Как открыть экран: путь указан в скобках. 🔒 — магазин, трогаем только по твоему прямому решению.

## 1. Баги точек входа — нужно твоё решение

- [ ] **`/buy` должен вести туда же, куда «Купить VPN / Продлить VPN»** (у активного подписчика — «📦 Управление подпиской»). Сейчас `/buy` сразу показывает список тарифов. *Рекомендую: да.*

- [ ] **`/support`** есть в меню команд, но бот на неё не отвечает. Сделать, чтобы открывалась «Помощь»? *Рекомендую: да.*
- [ ] **`/instruction`** открывает старый экран инструкции, а «Помощь → Инструкции» — выбор устройства. Сделать одинаково (выбор устройства)? *Рекомендую: да.*
- [ ] **`/connect`** — копия экрана выбора устройства без синхронизации с панелью. Вести на тот же экран, что «Подключить VPN»? *Рекомендую: да.*
- [ ] **`/start` каждый раз спрашивает язык**, даже у постоянных юзеров. Так и задумано?
- [ ] **Игры: «Назад» с экрана «боулинг закрыт»** ведёт в главное меню, а с «кубик уже брошен» — в меню игр. Сделать везде «К играм»?
- [ ] **Бомбер:** добавить на поле кнопку «🔙 К играм», чтобы из игры можно было выйти всегда?
- [ ] **Ввод промокода и суммы пополнения:** добавить кнопку «Отмена» (сейчас её нет, и любой текст считается промокодом или суммой)?

## 6. Старая админка в боте

С июня `/admin` показывает только «Открыть дашборд». Старое меню открывается, если нажать «Назад» в `/promo_stats`. Отметь то, чем **пользуешься именно в боте**, а не в дашборде:

- [ ] Статистика / аналитика / метрики
- [ ] Рефералы (статистика, поиск, топ)
- [ ] Карточка пользователя: выдать / отозвать доступ, VIP, скидки, смена тарифа, баланс
- [ ] **Перевыпуск ключа пользователю** (`/reissue_key` или кнопка в карточке)
- [ ] Трафик пользователя (добавить / убавить ГБ)
- [ ] Рассылки и центр уведомлений (промо, ретеншн, x2-кешбэк)
- [ ] Гифт-ссылки на ГБ
- [ ] Промокоды (`/promo_stats`, создание)
- [ ] Экспорт CSV, аудит, инцидент-баннер
- [ ] 🎁 Выдать бонус (раздача ГБ/дней)
- [ ] 🌪 Шторм на ферме
- [ ] Разовые инструменты: «Откат premium ×10y», «Аудит активных подписок», «Аудит БД дат», «Trial → промо −30 %»
- [ ] Ключи (legacy), QoDev, тест-меню, массовое создание в Remnawave
- [ ] `/pending_activations`, `/admin_audit`, `/notify_no_subscription`

Остаются в боте в любом случае: `/admin` (вход в дашборд), сброс пароля, доставка Apple ID / Spotify 🔒, «Написать пользователю», `/aggregator`-команды, `/wata_status`, `/id`.
