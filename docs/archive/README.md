# docs/archive — архив документации

Дата переноса: 2026-09-13 (пакет B1 из `docs/audit/01_dead_code.md`).

Здесь лежат **исторические документы, не отражают текущее состояние; актуальное — `docs/audit/`**.
Это старые аудиты, планы рефакторинга, legacy-описания samopis/Xray, «enterprise-шаблон»
и отчёты нагрузочных тестов за февраль 2026. Файлы перенесены через `git mv`, история сохранена.

Структура повторяет исходную:

- `root/` — файлы из корня репо (`*AUDIT*.md`, `I18N_*.md`, `LANGUAGE_REFACTOR_PLAN.md` и др.),
  `root/load_tests/results/` — отчёты из `load_tests/results/`;
- `audit/` — старые файлы из `docs/audit/` (февраль 2026);
- остальное — бывшие `docs/<файл>` и `docs/<папка>/`.

Код и CI эти файлы не читают. Ссылки внутри архивных файлов указывают на старые пути и не обновлялись.
