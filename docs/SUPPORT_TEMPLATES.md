# Готовые инструкции для поддержки

Копируй нужный блок целиком (включая эмодзи-заголовок и подпись в
конце) — можно сразу вставлять в Telegram. Стиль синхронизирован с
двумя закреплёнными сообщениями («Как подключить VPN», «Как добавить
устройство»).

Плейсхолдеры, которые везде используются:
- Бот: `@atlassecure_bot`
- Поддержка: `@atlas_suppbot`
- Меню бота открывается **синей кнопкой «Меню» слева внизу** (Telegram
  подставляет её автоматически, если бот прописал команды).

## ❌ Что делать, если оплата не прошла

❌ <b>Оплата не прошла — что делать</b> 🧡

Разберём по шагам 👇

<b>1. Проверь SMS от банка</b>
Если пришло <i>«Операция отклонена»</i> без списания — попробуй заново с другой карты или через СБП.

<b>2. Проверь лимиты</b>
СБП: некоторые банки ставят суточный лимит 15 000 ₽ по операциям в один адрес. Проверь в приложении банка.

<b>3. Проверь баланс и статус карты</b>
Иногда карта заблокирована банком по антифроду при первом платеже — позвони в поддержку банка и подтверди операцию.

<b>4. Жми «🔄 Попробовать снова»</b>
На экране «Оплата не прошла» есть эта кнопка — она вернёт тебя к выбору способа оплаты. Попробуй другой канал (СБП вместо карты и т.п.).

<b>5. Если <b>деньги списались</b>, но VPN не активировался</b>
Сохрани <b>код обращения</b> (WATA-XXXXXXXX-...) из сообщения бота и напиши в поддержку — мы сверим и вернём средства либо активируем подписку вручную.

<blockquote>💡 В 95% случаев Declined = деньги <b>не списаны</b>. Если списание есть, банк вернёт hold через 3-7 дней автоматически.</blockquote>

💬 Пиши в поддержку с кодом обращения — @atlas_suppbot 🧡

## 🔄 Что делать, если VPN не работает

🔄 <b>VPN не работает — диагностика</b> 🧡

Разберём по шагам 👇

<b>1. Проверь подписку</b>
/start → «<b>Моя подписка</b>» — активна ли, не истекла ли.

<b>2. Проверь остаток ГБ</b> (только для обхода)
/white — если 0 ГБ, обход не пропустит. Основной VPN работает без лимитов.

<b>3. Пересоздай подключение в приложении</b>
Открой Happ / Incy → удали профиль → добавь заново через кнопку «<b>Установить в Happ</b>» / «<b>Установить в Incy</b>» из /white.

<b>4. Проверь, не превышен ли лимит устройств</b>
«<b>Мои устройства</b>» — если 10/10, удали лишние.

<b>5. Смени сервер</b>
В приложении Happ/Incy можно вручную переключиться между серверами — иногда помогает.

<b>6. Перезапусти интернет</b>
Отключи и включи Wi-Fi / мобильный интернет.

<b>7. Обнови приложение</b>
Убедись, что Happ / Incy — последней версии из App Store / Google Play.

<blockquote>🆘 Если ничего не помогло — напиши в поддержку с описанием: какой тариф, какое устройство/ОС, какое приложение, что именно не работает (сайт не открывается / скорость / вообще нет подключения).</blockquote>

💬 Пиши в поддержку — @atlas_suppbot 🧡

## 🔁 Как оформить автопродление подписки

Не забываешь про продление — подписка продлевается сама 👇

<b>Вариант 1: Автопродление с баланса</b>

<b>1.</b> Пополни баланс на сумму, покрывающую следующее списание (см. «Как пополнить баланс»)

<b>4.</b> Если баланса не хватило — придёт напоминание, продление отложится до пополнения

<b>Вариант 2: СБП-подписка (авто-списание из банка)</b>

<b>1.</b> При оформлении подписки выбери способ <b>«🔄 СБП-подписка (авто-продление)»</b>

<b>2.</b> На экране банка подтверди привязку счёта (окно активно <b>30 минут</b>)

<b>3.</b> Первое списание пройдёт сразу — VPN активируется автоматически

<b>4.</b> Далее каждый месяц <b>сумма списывается сама</b>, без твоего участия

<blockquote>💡 Отменить СБП-подписку можно, написав в поддержку. Автопродление с баланса — тумблером в профиле в любой момент.</blockquote>

## ⚠️ Общие правила поведения в поддержке

**Внутренние гайды для операторов (не для юзеров):**

1. **Всегда** проси у юзера **код обращения** (WATA-XXX / PLTG-XXX / telegram_id), чтобы найти его в дашборде.
2. Если юзер жалуется «оплата прошла, VPN не активировался» — сначала посмотри `/dashboard/payments` по этому telegram_id: **паиpaid** — заведи ручной grant; **pending** — либо reconciler ещё не сработал, либо Wata retention удалила ссылку.
3. Если TRA_2999 / Declined webhook — деньги **не списаны**, юзер может просто попробовать заново.
4. Если пришёл alert «orphan webhook» — найди по transactionId в кабинете Wata, руками активируй / верни.
5. Все команды которые доступны юзерам: `/start` `/buy` `/white` `/hwadd` — они видны в синей кнопке «Меню» слева.
