- **Кнопки удалённых функций в уже отправленных сообщениях** (`admin:*` / `admin_*`, `broadcast:*`, `withdraw_*`, `biz_*`, `corporate_access_request`, `renewal_pay:`, `pay:sbp_sub`, `*lava*` и др.) новым кодом не выпускаются. - **Порядок роутеров:** callbacks → user → payments → admin → game → unknown (последним). Все 31 `Router()` подключены.
- **Deep links `/start`:** `bgift_`, `gift_`, `s-`, `p-`, `refd_`, `ref_` — все вызываемые функции существуют. Самореферал заблокирован, битые id ловятся.
